# Gabriel Mosca – Portfolio

Personal portfolio site. Plain HTML, CSS and JavaScript, so it runs on GitHub Pages for free with no build step.

## What's in here

| Path | What it is |
|---|---|
| `index.html` | Home page: intro, project write-ups, skills, contact |
| `projects/maple-bean/` | Maple & Bean Q3 sales dashboard |
| `projects/maple-bean/data/` | The dashboard's 5 CSV files go here (see below) |
| `projects/replay-log/` | Replay Log trading journal (demo opens with sample sessions) |
| `projects/parlay-lab/` | Parlay Lab expected-value calculator |

## Put it online (about 10 minutes)

1. Sign in at github.com (free account).
2. Create a new repository named exactly `YOUR-USERNAME.github.io` and set it to **Public**.
3. Click **Add file → Upload files**, drag in everything from this folder (keep the folders), then **Commit changes**.
4. Go to **Settings → Pages**. Under "Build and deployment", pick **Deploy from a branch**, branch `main`, folder `/ (root)`, and save.
5. After a minute or two the site is live at `https://YOUR-USERNAME.github.io`.

## Before you share it

- **Dashboard data:** copy these five files into `projects/maple-bean/data/`:
  `monthly.csv`, `weekly.csv`, `weekday.csv`, `hourly.csv`, `items.csv`.
  Until they're there, the dashboard page shows a short note and empty charts.
- **Links:** in `index.html`, search for `YOUR-HANDLE` and `YOUR-USERNAME`, fill in your LinkedIn and GitHub, and remove the `<!--` and `-->` around those two lines.
- **Check every page** on your phone and computer, and click every link.

## Updating later

Edit a file on GitHub (pencil icon) or upload a new version. The live site updates within a couple of minutes.
